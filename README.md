# E-portfolio – IT-ledelse, AAU

En statisk e-portfolio hjemmeside udviklet som en del af studiet på IT-ledelse ved Aalborg Universitet. Hjemmesiden præsenterer en fiktiv virksomhed med ydelser inden for webdesign og AI-implementering.

---

## Projektbeskrivelse

Projektet er en multi-side hjemmeside bygget med HTML og CSS, versionsstyret via Git og GitHub. Formålet er at dokumentere gruppens kompetencer og udviklingsproces, herunder design, kode og samarbejde.

---

- **GitHub Projects** – projektstyring via Kanban-board

---

## Projektstyring

Vi har brugt **Kanban** via GitHub Projects til at styre arbejdet. Opgaver blev fordelt som kort på boardet og flyttet fra "To do" over "In progress" til "Done". Vi valgte Kanban frem for Scrum, da vi ikke havde en fast deadline og ønskede at alle gruppemedlemmer fik mulighed for at bidrage til udviklingen.

---

## Gruppemedlemmer og roller

| Navn | Ansvarsområde |
|---|---|
| **Johan** | Prisliste-siden, navigation, CSS-struktur (`style.css` og `layout.css`), prototype, UML-diagrammer, teknisk dokumentation |
| **Sofie** | Forside (`index.html`), Om os-siden, Kanban-board, dokumentation af styringsværktøj |
| **Aydasu** | FAQ-siden, Projektsiden, projektbeskrivelse, rollebeskrivelse, GitHub Projects |

Alle gruppemedlemmer har bidraget til kodning og arbejdet efter princippet om *Collective Ownership*, hvor hele kodebasen er fælles ansvar.

---

## Kom i gang

Hjemmesiden er statisk og kræver ingen server. Åbn `html/index.html` direkte i en browser.
