# **E-portfolio – IT-ledelse, AAU**
Hjemmeside udviklet som studieprojekt på IT-ledelse ved Aalborg Universitet. Hjemmesiden præsenterer en fiktiv virksomhed med ydelser inden for webdesign og AI.

**Sider**
* index.html – Forside
* about.html – Om os
* presentation.html – Projektoversigt
* pricing.html – Prisliste med interaktiv dropdown
* ai.html – AI Services med bestillingssystem
* faq.html – Ofte stillede spørgsmål

**Teknologier**
* HTML og CSS
* JavaScript
* Git og GitHub til versionsstyring
* GitHub Projects til projektstyring (Kanban)
* UML-diagrammer
